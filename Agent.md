# CrewConnect — AI Event Staffing

## Hackathon Demo Agenda

### 1. Problem

* Event organizers struggle to find reliable event workers quickly.
* Manual staffing makes it difficult to compare availability, skills, location, reliability, and cost.
* Last-minute worker cancellations can disrupt an event.

### 2. CrewConnect Solution

* Connect event organizers with verified freelance workers.
* Check worker availability for the event.
* Use AI-powered matching to recommend the best crew.
* Provide backup workers for critical roles.
* Handle confirmation, replacement, and payment workflows.

### 3. Live Demo — Create Event

* Show event requirements, roles, budget, date, and location.

  * Availability

  * Rating

### 6. Primary & Backup Crew

* Show the recommended primary crew.

### 8. AI Recascading — No-Show Scenario

* Simulate a primary worker becoming unavailable.
* Show the AI identifying the next-best eligible backup.
* Demonstrate automatic replacement/re-cascading.
* Confirm the replacement worker.

### 9. Payment & Escrow

* Show the confirmed crew payment amount.
* Create the escrow/payment record.
* Demonstrate payment being held until the event is completed.
* Release payment to the workers.
* Show the payment/ledger history.

### 10. Key Value Proposition

**CrewConnect doesn't just find workers.**

It provides an end-to-end staffing workflow:

**Availability → AI Matching → Primary Crew → Backups → Confirmation → Recascading → Replacement → Escrow → Payment**

### 11. Closing

* Faster staffing
* Better worker matching
* Reliable backup coverage
* Automated response to no-shows
* Transparent payment workflow

**CrewConnect — Smarter staffing for better events.**
